# Отчет о проверке реализации на соответствие ТЗ

## 1. Система видимости

### ✅ Реализовано:
- [x] Хранение `visibility_level`, `is_fog`, `weather_track` в таблице `games`
- [x] Сброс обнаружения при тумане (`ResetDetectionInFog`)
- [x] Сброс обнаружения при видимости X (`ResetAllDetection`)
- [x] Базовая фаза видимости (`VisibilityPhaseHandler`)

### ❌ НЕ реализовано:
- [ ] **Расчет уровня видимости по формуле**: Статус погоды + Модификатор времени суток
  - Сейчас: хардкод `visibilityLevel = 3`
  - Требуется: расчет с учетом времени суток (День: +0, Ночь: +3)
- [ ] **Бросок d10 по Таблице изменения погоды** в фазе видимости
- [ ] **Смещение маркера погоды по Треку погоды**
- [ ] **Определение тумана по погоде 5-9** (сейчас хардкод `isFog = true`)
- [ ] **Проверка особого расхода топлива**: погода = 9 и бросок 0-4 → все корабли тратят 1 FP
- [ ] **Хранение/расчет времени суток** (день/ночь)

### ⚠️ Частично реализовано:
- Сброс обнаружения в туманных гексах работает глобально, но нет проверки конкретных туманных гексов

---

## 2. Система поиска

### ✅ Реализовано:
- [x] Расчет факторов поиска в гексе (`SearchService.CalculateSearchFactors`)
- [x] Учет кораблей/ТФ: +1 за каждый
- [x] Учет маркеров Пути полета Поиска: +2 за каждый
- [x] Учет маркеров Морского патруля: +3 за каждый (корабли и ТФ)
- [x] Фильтрация по стороне игрока (только свои факторы поиска)
- [x] API endpoint для массового расчета факторов поиска
- [x] Базовая фаза поиска (`SearchPhaseHandler`)
- [x] Проверка условий поиска (видимость X, туман)

### ❌ НЕ реализовано:
- [ ] **Собственные Факторы поиска кораблей** (переменные, из конфигурации) - не учитываются в расчете
- [ ] **Исключения из факторов поиска**:
  - Корабли, проводившие попытку преследования в этот ход
  - Корабли, заправляющиеся (в море или в порту) - частично проверяется
  - Корабли, проводящие ремонт в море - частично проверяется
- [ ] **Процедура поиска**:
  - **Автоматический поиск по всем гексам** с Факторами поиска ≥ Уровень видимости
  - Обработка результатов поиска (противник сообщает информацию о юнитах)
  - Размещение маркеров "Обнаружено"/"Преследуется"
  - Обработка особого случая (поиск гекса, через который корабль прошел)
  - Удаление маркеров Пути полета Поиска в конце фазы
- [ ] **API endpoint для автоматического выполнения поиска** (сканирование всех подходящих гексов и обработка результатов)

### ⚠️ Частично реализовано:
- Метод `DetectUnitsInHex` существует, но нет полной процедуры поиска
- Метод `SearchUnit` существует, но не реализована логика обнаружения

## 3. Система обнаружения

### ✅ Реализовано:
- [x] Типы маркеров: `sighted` (Обнаружено), `shadowed` (Преследуется)
- [x] Хранение `detection_level` на юнитах и ТФ
- [x] Метод `DetectUnitsInHex` для обнаружения при поиске
- [x] Переход Shadowed → Sighted в конце фазы движения
- [x] Удаление оставшихся Sighted после фазы преследования
- [x] Сброс обнаружения при тумане/видимости X
- [x] Базовая фаза преследования (`ShadowPhaseHandler`)

### ❌ НЕ реализовано:
- [ ] **Процедура преследования (Фаза преследования)**:
  - Проверка условий преследования (цель Sighted, в одном гексе)
  - Бросок по Таблице преследования (0-4 = Успех, 5-9 = Провал)
  - **Модификаторы броска**:
    - Разница в рейтинге уклонения
    - Радар преследующего (Radar I/II)
    - Уровень видимости
    - Маневр уклонения (+2, трата 2 FP)
    - Маневр отвлечения (+2, трата 1 FP всеми кораблями ТФ, разделение ТФ)
  - Переход Sighted → Shadowed при успехе
  - Запрет поиска для юнита, проводившего преследование
  - Разрешения: Союзники - морские и воздушные, Немцы - только воздушные
- [ ] **Случайное обнаружение (Фаза случайных событий)**:
  - Броски для немецких кораблей/ТФ
  - Таблица случайного обнаружения по видимости и местоположению
  - Полное обнаружение vs Пеленг
- [ ] **Охота на конвои (Фаза случайных событий)**
- [ ] **API endpoint для попытки преследования**
- [ ] **Обработка маневров уклонения и отвлечения**

### ⚠️ Частично реализовано:
- Фаза случайных событий (`ChancePhaseHandler`) существует, но логика не реализована (TODO)

## 4. Система движения

### ✅ Реализовано:
- [x] Ограничения движения (гексы без координат, суша)
- [x] Классы скорости (VS, S, M, F) и их правила
- [x] Отслеживание расхода топлива
- [x] Task Forces: движение со скоростью самого медленного корабля
- [x] Создание/разделение ТФ
- [x] Аварийное топливо
- [x] Базовая фаза движения (`MovementPhaseHandler`)
- [x] Приоритет движения преследуемых (логирование)

### ❌ НЕ реализовано:
- [ ] **Приоритет движения**:
  - Преследуемые двигаются первыми
  - Обязательное объявление местоположения противнику
  - Если у обеих сторон преследуемые → немецкий игрок первым
- [ ] **Проверка туманных гексов при движении**:
  - Преследуемый входит в туманный гекс → убрать маркер "Преследуется"
  - Первый туманный гекс все равно объявляется противнику
- [ ] **MVD (Movement Vector Data)**: отслеживание переворота жетона на сторону с MVD
- [ ] **Воздушные юниты**:
  - Игнорирование рельефа
  - Маркеры пути полета (2 бесплатных, дополнительные стоят Уровень видимости MP)
  - Ограничения размещения маркеров

### ⚠️ Частично реализовано:
- Проверка Kaiser Wilhelm Canal (возможно реализована в movement_service, нужно проверить)

1. **Критично** (для полноценной игры):

   - Процедура поиска (объявление гексов, получение результатов)
   - Процедура преследования (броски, модификаторы)

2. **Важно**:
   - Случайное обнаружение в фазе случайных событий
   - Приоритет движения преследуемых
   - Собственные факторы поиска кораблей

3. **Улучшения**:
   - Охота на конвои
   - Маневры уклонения/отвлечения
   - Воздушные юниты и маркеры пути полета
