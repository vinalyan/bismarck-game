### 3. Дублирование логики получения UserID из контекста

Проблема: две разные реализации получения UserID.

- `handlers/game_handler.go:getUserIDFromContext` (строки 42-51):
  - Принимает `*http.Request`
  - Возвращает `(string, error)`

- `middleware/auth.go:GetUserIDFromContext` (строки 128-131):
  - Принимает `context.Context`
  - Возвращает `(string, bool)`

Рекомендация:
- Удалить `getUserIDFromContext` из `game_handler.go`
- Использовать `middleware.GetUserIDFromContext(r.Context())` везде
- Добавить helper в `game_handler.go`:
```go
func getUserIDFromRequest(r *http.Request) (string, error) {
    userID, ok := middleware.GetUserIDFromContext(r.Context())
    if !ok {
        return "", fmt.Errorf("user_id not found in context")
    }
    return userID, nil
}
```
