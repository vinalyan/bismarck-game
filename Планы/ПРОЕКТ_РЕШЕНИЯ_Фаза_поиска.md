# Проект решения: Реализация фазы поиска с использованием GameModel

## Статус использования MCP инструментов
- ✅ MCP sequential-thinking использован для структурированного анализа
- ❌ MCP context7 не использован (не требовался для анализа кодовой базы)

---

## 1. Архитектурный обзор

### 1.1. Основной принцип
**Использовать GameModel как единственный источник данных:**
- `GameModel.Search` - для факторов поиска
- `GameModel.Units` - для поиска вражеских юнитов
- `GameModel.TaskForces` - для поиска вражеских Task Forces
- Обновление `DetectionLevel` - через `UpdateGameModelWithRetry()`

**НЕ использовать запросы к БД:**
- ❌ `SearchService.CalculateSearchFactors()` - факторы уже в `GameModel.Search`
- ❌ `collectCandidateHexes()` - гексы берутся из `GameModel.Search`
- ❌ `getEnemyUnitsInHex()` с запросами к БД - использовать `GameModel.Units`
- ❌ `getEnemyTaskForcesInHex()` с запросами к БД - использовать `GameModel.TaskForces`
- ❌ `UnitService.UpdateUnitDetectionLevel()` - обновлять через `GameModel`
- ❌ `TaskForceService.UpdateTaskForceDetectionLevel()` - обновлять через `GameModel`

### 1.2. Ключевые изменения
1. **Загрузка GameModel один раз** в начале фазы
2. **Использование GameModel.Search** вместо пересчета факторов
3. **Поиск вражеских юнитов/ТФ** из `GameModel.Units` и `GameModel.TaskForces`
4. **Обновление DetectionLevel** через `UpdateGameModelWithRetry()`
5. **Синхронизация видимости** через `VisibilityService` (остается, так как это специфичная информация для каждого игрока)

## 2. Структура решения

### 2.1. Модуль 1: Предварительные проверки и загрузка данных

**Функция:** `SearchPhaseHandler.Start()`

**Алгоритм:**
```
1. Загрузить GameModel через GameStateService.LoadGameModel(gameID)
   - ОДИН РАЗ в начале фазы
   - Использовать эту модель для всех операций

2. Проверить visibility_level:
   - Если >= 10 → завершить фазу сразу (удалить маркеры flight_path_search)
   - Иначе → продолжить

3. Проверить GameModel.Search:
   - Если nil → инициализировать пустыми структурами
   - Если German/Allied == nil → инициализировать пустыми мапами

4. Выполнить автосброс: Shadowed → Sighted (существующая логика)
```

**Зависимости:**
- `GameStateService.LoadGameModel()` - загрузка GameModel
- `GameStateService.GetGameVisibilityOnly()` - получение visibility_level

---

### 2.2. Модуль 2: Обработка поиска для каждой стороны

**Функция:** `SearchPhaseHandler.executeSearchForSide()` (полный рефакторинг)

**Алгоритм:**
```
1. Определить раздел GameModel.Search:
   - Для союзников: GameModel.Search.Allied
   - Для немцев: GameModel.Search.German

2. Итерация по всем гексам в выбранном разделе:
   Для каждой записи (hex_id, searchHexData) в GameModel.Search.[Allied|German]:
   
   a. Проверка условий:
      - searchHexData.Factor >= visibilityLevel? 
        → Если нет → пропустить гекс (логировать: "недостаточно факторов")
      - isFog && гекс туманный?
        → Если да → пропустить гекс (логировать: "пропущен: туман")
   
   b. Определение DetectionLevel:
      - Если searchHexData.AirSearch > 0:
        → DetectionLevel = SHADOWED
      - Иначе:
        → DetectionLevel = SIGHTED
   
   c. Поиск вражеских юнитов ИЗ GAMEMODEL:
      - Найти в GameModel.Units все юниты с:
        * Position == hex_id
        * Nationality == opponentSide
        * Status != "sunk"
        * Category == "naval"
      
      - Найти в GameModel.TaskForces все ТФ с:
        * Position == hex_id
        * Nationality == opponentSide (или Owner == opponentPlayerID)
   
   d. Обработка результатов:
      - Если нет вражеских юнитов/ТФ:
        → Логировать: "Search «hex <HEX_ID>: нет контакта»"
        → Продолжить следующий гекс
      - Если есть вражеские юниты/ТФ:
        → Применить DetectionLevel через UpdateGameModelWithRetry()
        → Логировать результаты
        → Синхронизировать видимость через VisibilityService
```

**Изменения в коде:**
- ❌ Убрать вызов `collectCandidateHexes()`
- ❌ Убрать вызов `CalculateSearchFactors()`
- ❌ Убрать вызов `hexHasFlightPathMarker()`
- ❌ Убрать вызов `getEnemyUnitsInHex()` с запросами к БД
- ❌ Убрать вызов `getEnemyTaskForcesInHex()` с запросами к БД
- ✅ Заменить на чтение из `GameModel.Search.[Allied|German]`
- ✅ Заменить на фильтрацию `GameModel.Units` и `GameModel.TaskForces`

### 2.3. Модуль 3: Поиск вражеских юнитов из GameModel

**Новая функция:** `findEnemyUnitsInHexFromModel()`

```go
func (h *SearchPhaseHandler) findEnemyUnitsInHexFromModel(
    model *models.GameModel,
    hexID string,
    opponentPlayerID string,
    opponentSide string,
) []*models.UnitModel {
    var enemyUnits []*models.UnitModel
    
    for _, unit := range model.Units {
        // Проверка позиции
        if unit.Position != hexID {
            continue
        }
        
        // Проверка категории (только морские юниты)
        if unit.Category != models.UnitCategoryNaval {
            continue
        }
        
        // Проверка статуса
        if unit.Status == "sunk" {
            continue
        }
        
        // Проверка владельца/национальности
        if !h.isEnemyUnit(unit, opponentPlayerID, opponentSide) {
            continue
        }
        
        enemyUnits = append(enemyUnits, unit)
    }
    
    return enemyUnits
}
```

**Новая функция:** `findEnemyTaskForcesInHexFromModel()`

```go
func (h *SearchPhaseHandler) findEnemyTaskForcesInHexFromModel(
    model *models.GameModel,
    hexID string,
    opponentPlayerID string,
    opponentSide string,
) []*models.TaskForceModel {
    var enemyTaskForces []*models.TaskForceModel
    
    for _, tf := range model.TaskForces {
        // Проверка позиции
        if tf.Position != hexID {
            continue
        }
        
        // Проверка владельца/национальности
        if !h.isEnemyTaskForce(tf, opponentPlayerID, opponentSide) {
            continue
        }
        
        enemyTaskForces = append(enemyTaskForces, tf)
    }
    
    return enemyTaskForces
}
```

**Вспомогательная функция:** `isEnemyUnit()`

```go
func (h *SearchPhaseHandler) isEnemyUnit(
    unit *models.UnitModel,
    opponentPlayerID string,
    opponentSide string,
) bool {
    // Проверка по PlayerID
    if opponentPlayerID != "" && unit.Owner == opponentPlayerID {
        return true
    }
    
    // Проверка по стороне (Nationality)
    if opponentSide != "" && unit.Nationality == opponentSide {
        return true
    }
    
    return false
}
```

### 2.4. Модуль 4: Обновление DetectionLevel через GameModel

**Новая функция:** `applyDetectionToUnitsInModel()`

```go
func (h *SearchPhaseHandler) applyDetectionToUnitsInModel(
    pm *PhaseManager,
    gameID string,
    hexID string,
    playerID string,
    sideLabel string,
    level models.DetectionLevel,
    unitIDs []string, // IDs юнитов для обновления
) error {
    if pm.gameStateService == nil {
        return fmt.Errorf("gameStateService is required")
    }
    
    // Обновляем через GameModel
    err := pm.gameStateService.UpdateGameModelWithRetry(gameID, func(model *models.GameModel) error {
        // Обновляем DetectionLevel для каждого юнита
        for _, unitID := range unitIDs {
            unit, exists := model.Units[unitID]
            if !exists {
                log.Printf("Search phase - unit %s not found in GameModel", unitID)
                continue
            }
            
            // Проверяем, что это морской юнит
            if unit.Category != models.UnitCategoryNaval || unit.NavalData == nil {
                continue
            }
            
            // Обновляем DetectionLevel
            oldLevel := unit.NavalData.DetectionLevel
            unit.NavalData.DetectionLevel = level
            
            // Логируем переход
            if oldLevel != level {
                log.Printf("Detection «unit %s: status %s → %s (hex %s)»", 
                    unit.Name, oldLevel, level, hexID)
            }
        }
        
        return nil
    }, 3)
    
    if err != nil {
        return fmt.Errorf("failed to update units detection level: %w", err)
    }
    
    // Синхронизируем видимость через VisibilityService
    for _, unitID := range unitIDs {
        h.updateUnitVisibility(pm, gameID, playerID, unitID, hexID, level)
    }
    
    return nil
}
```

**Новая функция:** `applyDetectionToTaskForcesInModel()`

```go
func (h *SearchPhaseHandler) applyDetectionToTaskForcesInModel(
    pm *PhaseManager,
    gameID string,
    hexID string,
    playerID string,
    sideLabel string,
    level models.DetectionLevel,
    tfIDs []string, // IDs Task Forces для обновления
) error {
    if pm.gameStateService == nil {
        return fmt.Errorf("gameStateService is required")
    }
    
    // Обновляем через GameModel
    err := pm.gameStateService.UpdateGameModelWithRetry(gameID, func(model *models.GameModel) error {
        // Обновляем DetectionLevel для каждой ТФ
        for _, tfID := range tfIDs {
            tf, exists := model.TaskForces[tfID]
            if !exists {
                log.Printf("Search phase - task force %s not found in GameModel", tfID)
                continue
            }
            
            // Обновляем DetectionLevel ТФ
            oldLevel := models.DetectionLevel(tf.DetectionLevel)
            tf.DetectionLevel = string(level)
            
            // Логируем переход
            if oldLevel != level {
                log.Printf("Detection «TF %s: status %s → %s (hex %s)»", 
                    tf.Name, oldLevel, level, hexID)
            }
            
            // Обновляем DetectionLevel для всех кораблей в ТФ
            for _, unitID := range tf.Units {
                unit, exists := model.Units[unitID]
                if !exists {
                    continue
                }
                
                if unit.Category != models.UnitCategoryNaval || unit.NavalData == nil {
                    continue
                }
                
                oldUnitLevel := unit.NavalData.DetectionLevel
                unit.NavalData.DetectionLevel = level
                
                if oldUnitLevel != level {
                    log.Printf("Detection «unit %s (in TF %s): status %s → %s (hex %s)»", 
                        unit.Name, tf.Name, oldUnitLevel, level, hexID)
                }
            }
        }
        
        return nil
    }, 3)
    
    if err != nil {
        return fmt.Errorf("failed to update task forces detection level: %w", err)
    }
    
    // Синхронизируем видимость через VisibilityService
    for _, tfID := range tfIDs {
        tf, exists := model.TaskForces[tfID]
        if !exists {
            continue
        }
        
        // Обновляем видимость для всех кораблей в ТФ
        for _, unitID := range tf.Units {
            h.updateUnitVisibility(pm, gameID, playerID, unitID, hexID, level)
        }
    }
    
    return nil
}
```

## 4. Детали реализации

### 4.1. Загрузка GameModel

```go
// В Start():
model, err := pm.gameStateService.LoadGameModel(gameID)
if err != nil {
    log.Printf("Search phase - failed to load GameModel: %v", err)
    return err
}

// Передавать model в executeSearchForSide()
h.executeSearchForSide(pm, gameID, model, ctx.visibilityLevel, ctx.isFog, side)
```

### 4.2. Итерация по гексам из GameModel.Search

```go
// В executeSearchForSide():
// Получить раздел Search для стороны
var searchData map[string]models.SearchHexData
if side.label == "allied" {
    if model.Search == nil || model.Search.Allied == nil {
        log.Printf("Search phase - no Allied search data")
        return
    }
    searchData = model.Search.Allied
} else {
    if model.Search == nil || model.Search.German == nil {
        log.Printf("Search phase - no German search data")
        return
    }
    searchData = model.Search.German
}

// Итерация по гексам
for hexID, searchHexData := range searchData {
    // Проверка Factor >= visibilityLevel
    if searchHexData.Factor < visibilityLevel {
        log.Printf("Search phase - skipping hex %s: insufficient factors (%d < %d)", 
            hexID, searchHexData.Factor, visibilityLevel)
        continue
    }
    
    // Проверка тумана
    if isFog && h.isHexFogged(pm, hexID) {
        h.logSearchResult(..., "пропущен: туман")
        continue
    }
    
    // Определение DetectionLevel
    detectionLevel := models.DetectionLevelSighted
    if searchHexData.AirSearch > 0 {
        detectionLevel = models.DetectionLevelShadowed
    }
    
    // Поиск вражеских юнитов ИЗ GAMEMODEL
    enemyUnits := h.findEnemyUnitsInHexFromModel(model, hexID, side.opponentPlayerID, side.opponentLabel)
    enemyTaskForces := h.findEnemyTaskForcesInHexFromModel(model, hexID, side.opponentPlayerID, side.opponentLabel)
    
    // Обработка
    if len(enemyUnits) == 0 && len(enemyTaskForces) == 0 {
        h.logSearchResult(..., "нет контакта")
        continue
    }
    
    // Применить DetectionLevel ЧЕРЕЗ GAMEMODEL
    unitIDs := make([]string, 0, len(enemyUnits))
    for _, unit := range enemyUnits {
        unitIDs = append(unitIDs, unit.ID)
    }
    h.applyDetectionToUnitsInModel(pm, gameID, hexID, side.playerID, side.label, detectionLevel, unitIDs)
    
    tfIDs := make([]string, 0, len(enemyTaskForces))
    for _, tf := range enemyTaskForces {
        tfIDs = append(tfIDs, tf.ID)
    }
    h.applyDetectionToTaskForcesInModel(pm, gameID, hexID, side.playerID, side.label, detectionLevel, tfIDs)
    
    // Логирование
    h.logSearchResult(...)
    h.logSearchWarning(...)
}
```

## 6. Обработка ошибок

### 6.1. Ошибки загрузки GameModel
- Если `GameModel` не найден → завершить фазу с ошибкой
- Логировать критическую ошибку

### 6.2. Ошибки доступа к GameModel.Search
- Если `Search == nil` → инициализировать пустыми структурами
- Если для гекса нет данных в `Search` → пропустить гекс
- Продолжить обработку следующих гексов

### 6.3. Ошибки обновления DetectionLevel через GameModel
- Если `UpdateGameModelWithRetry()` вернул ошибку → логировать ошибку
- Попытаться продолжить с остальными юнитами
- Не прерывать всю фазу поиска

### 6.4. Ошибки обновления видимости
- Логировать предупреждение
- `DetectionLevel` уже установлен в GameModel, видимость можно синхронизировать позже

## 7. Граничные случаи

| Случай | Обработка |
|--------|-----------|
| `visibility_level >= 10` | Завершить фазу сразу, маркеры не устанавливаются |
| `GameModel.Search == nil` | Инициализировать пустыми структурами |
| Гекс отсутствует в `GameModel.Search` | Пропустить (нет факторов поиска) |
| `Factor < visibilityLevel` | Пропустить гекс (логировать) |
| Туманный гекс | Пропустить (не должен попадать в Search, но проверка нужна) |
| Нет вражеских юнитов в гексе | Логировать "нет контакта", продолжить |
| Несколько вражеских юнитов/ТФ в гексе | Все получают одинаковый `DetectionLevel` |
| Юнит не найден в `GameModel.Units` | Пропустить, логировать предупреждение |
| ТФ не найдена в `GameModel.TaskForces` | Пропустить, логировать предупреждение |

## 10. Преимущества нового подхода

1. **Производительность:**
   - Один запрос на загрузку GameModel вместо множественных запросов
   - Фильтрация в памяти вместо запросов к БД
   - Батчинг обновлений через одну транзакцию

2. **Консистентность:**
   - Все данные из одного источника (GameModel)
   - Нет рассинхронизации между БД и GameModel

3. **Простота:**
   - Меньше зависимостей от сервисов
   - Прямая работа с данными в памяти

4. **Масштабируемость:**
   - Легко добавить кэширование GameModel
   - Легко добавить оптимистичную блокировку

Проект готов к реализации. Все операции выполняются через GameModel без прямых запросов к БД (кроме синхронизации видимости, которая остается через VisibilityService).
