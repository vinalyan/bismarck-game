## Техническое задание на доработку системы видимости, поиска, обнаружения и движения

### 1. Система видимости

#### 1.1. Расчет уровня видимости
- **Формула**: Уровень видимости = Статус погоды + Модификатор времени суток
- **Модификаторы времени суток**:
  - День: +0
  - Ночь: +3
- **Диапазон**: 1 до X (где X — максимальная видимость, блокирует все действия)

#### 1.2. Фаза видимости (выполняется в начале хода, пропускается на 1-м ходу)
**Последовательность действий:**
1. Бросок d10 по Таблице изменения погоды
2. Смещение маркера погоды по Треку погоды
3. Проверка тумана:
   - Если погода 5-9 → возникает туман
   - Убрать все маркеры "Обнаружено" и "Преследуется" в туманных гексах
   - Запретить поиск, преследование и бой в туманных гексах
4. Расчет уровня видимости (погода + модификатор времени суток)
5. Проверка особого расхода топлива:
   - Если погода = 9 и бросок 0-4 → все корабли тратят 1 FP

#### 1.3. Ограничения при видимости
- **Видимость X**: запрещены поиск, преследование, бой
- Убрать все маркеры "Обнаружено" и "Преследуется" при видимости X
- **Туман**: при статусе погоды 5-9
  - Запрещены поиск, преследование, бой в туманных гексах
  - Снять все маркеры обнаружения в туманных гексах

### 2. Система поиска

#### 2.1. Условия поиска
- **Автоматический поиск**: Факторы поиска в гексе ≥ Уровень видимости
- Поиск происходит автоматически по всем гексам, где выполняются условия
- Запреты:
  - Видимость = X (поиск полностью заблокирован)
  - Туманные гексы во время тумана (поиск в туманных гексах заблокирован)
  - Владелец корабля сам сообщает, если собственные Факторы поиска ≥ Уровень видимости

#### 2.2. Расчет факторов поиска в гексе
Факторы суммируются из:
- Корабль или Оперативное соединение: +1 (ТФ = 1, независимо от числа кораблей)
- Маркер Пути полета Поиска: +2 (воздушный юнит)
- Маркер Морского патруля: +3
- Собственные Факторы поиска кораблей (переменные, из конфигурации)

#### 2.3. Исключения из факторов поиска
Не дают факторов поиска:
- Корабли, проводившие попытку преследования в этот ход
- Корабли, заправляющиеся (в море или в порту)
- Корабли, проводящие ремонт в море

#### 2.4. Процедура поиска
**Автоматический поиск:**
- Поиск происходит автоматически по всем гексам, где Факторы поиска ≥ Уровень видимости
- Система автоматически определяет все такие гексы для каждой стороны
- Порядок обработки: сначала Союзники, затем Немцы

**Последовательность для каждого гекса с достаточными факторами:**
1. Определение наличия противника в гексе
2. Если противник найден, противник сообщает:
   - Есть ли морской юнит в гексе
   - Если есть: количество кораблей, их классы, входят ли в ТФ
   - Индивидуальные названия не раскрываются
3. Размещение маркеров:
   - Если в гексе поиска есть маркер Пути полета Поиска → маркер "Преследуется"
   - Иначе → маркер "Обнаружено"
4. Особый случай: если ищут гекс, через который корабль прошел
   - Объявить текущее местоположение и общее количество кораблей (без классов)
   - Маркеры не ставятся, если в новом местоположении недостаточно Факторов поиска
5. В конце фазы: убрать все маркеры Пути полета Поиска

**Техническая реализация:**
- Система автоматически сканирует все морские гексы для каждой стороны
- Для каждого гекса вычисляются Факторы поиска
- Если Факторы поиска ≥ Уровень видимости → выполняется поиск в этом гексе
- Результаты поиска автоматически обрабатываются и применяются маркеры обнаружения

### 3. Система обнаружения

#### 3.1. Типы маркеров обнаружения
- **"Обнаружено" (SIGHTED)**: минимальная информация
- **"Преследуется" (SHADOWED)**: более точное отслеживание

#### 3.2. Способы обнаружения

**A. Активный поиск (Фаза поиска)**
- Условие: Факторы поиска ≥ Уровень видимости
- Результат: маркер "Обнаружено" или "Преследуется" (если есть маркер Пути полета Поиска)

**B. Преследование (Фаза преследования)**
- Игрок Союзников может преследовать морскими и воздушными юнитами
- Немецкий игрок может преследовать только воздушными юнитами
- Условия:
  - Цель должна иметь маркер "Обнаружено"
  - Преследующий и преследуемый в одном гексе
  - Только одна попытка на корабль/ТФ за ход

**Таблица преследования:**
- Базовый результат: 0-4 = Успех, 5-9 = Провал

**Модификаторы броска:**
- Разница в рейтинге уклонения:
  - +2 или более: -4
  - +1: -2
  - -1: +1
  - -2 или менее: преследование невозможно (NP)
- Радар преследующего:
  - Radar II: -2
  - Radar I: -1
- Уровень видимости:
  - 4-6: +1
  - 7-9: +3
  - X: NP
- Маневр уклонения: +2 (трата 2 FP, объявляется до броска)
- Маневр отвлечения: +2 (трата 1 FP всеми кораблями ТФ, разделение ТФ)

**Результат преследования:**
- Успех → маркер "Обнаружено" переворачивается на "Преследуется"
- После всех попыток → убрать оставшиеся маркеры "Обнаружено"
- Юнит, проводивший преследование, не может проводить поиск в этот ход

**C. Случайное обнаружение (Фаза случайных событий)**
- Броски для каждого немецкого корабля/ТФ (для ТФ — один кубик)
- Используется Таблица случайного обнаружения по пересечению уровня видимости и местоположения
- Местоположение:
  - В пределах границ воздушного сектора
  - В пределах границ воздушного сектора И в/смежно с гексом с собственным Фактором поиска Союзников
  - За пределами границ воздушного сектора

**Результаты:**
- Полное обнаружение (результат = значению обнаружения):
  - Объявить местоположение, класс(ы), количество кораблей
  - Поставить маркер "Преследуется"
- Пеленг (результат = 0):
  - Объявить только местоположение
  - Маркеры не ставятся

**D. Охота на конвои (Фаза случайных событий)**
- Обнаружение торговых судов и конвоев
- Результат броса 1: одиночное торговое судно → маркер "Обнаружено"
- Результат броса 0: возможный конвой → бросок на идентификацию

#### 3.3. Управление маркерами обнаружения
**Когда снимаются маркеры "Обнаружено":**
1. В Фазе преследования — после всех попыток убираются оставшиеся (не ставшие "Преследуется")
2. При тумане — убрать все маркеры "Обнаружено" и "Преследуется" в туманных гексах
3. При видимости X — убрать все маркеры "Обнаружено" и "Преследуется"

**Переходы между статусами:**
- В конце Фазы движения: все "Преследуется" → "Обнаружено"
- Для повторного "Преследуется" нужна успешная попытка преследования или обнаружение через воздушные юниты

#### 3.4. Информация при обнаружении
**Минимальная (при поиске):**
- Наличие юнита в гексе
- Количество кораблей
- Классы кораблей
- Входят ли в ТФ

**Полная (при полном обнаружении):**
- Местоположение
- Класс(ы)
- Количество кораблей (для ТФ)
- Постановка маркера "Преследуется"

### 4. Система движения

#### 4.1. Приоритет движения
- Преследуемые юниты двигаются первыми в Фазе движения
- Обязаны сообщить противнику новое местоположение
- Если у обеих сторон есть преследуемые корабли → немецкий игрок двигает первым
- После движения преследуемых → все остальные юниты

#### 4.2. Ограничения движения
- Корабли не могут входить в гексы без координат (hex ID)
- Нельзя пересекать стороны гексов, полностью занятые сушей
- Исключение: немецкие корабли могут двигаться через Kaiser Wilhelm Canal (гексы O32 ↔ O33)

#### 4.3. Классы скорости и правила движения

**VS — Очень медленный:**
- Макс. движение: 1 гекс за 4 хода
- После движения: маркер "Нет движения 4"
- Топливо: не используют

**S — Медленный:**
- Макс. движение: 1 гекс за 2 хода
- После движения: маркер "Нет движения 2"
- Топливо: не используют

**M — Средний:**
- Макс. движение: 1 гекс за ход
- Расход топлива:
  - Движение 1 гекс после движения 1 гекс в предыдущий ход → 1 FP
  - Иначе → 0 FP
- Отслеживание: перевернуть жетон на сторону с MVD после движения

**F — Быстрый:**
- Макс. движение: 2 гекса за ход
- Расход топлива:
  - Движение 0-1 гекс → 0 FP
  - Движение 2 гекса после 0-1 гекса в предыдущий ход → 1 FP
  - Движение 2 гекса после 2 гексов в предыдущий ход → 2 FP
- Ограничение: поврежденный корабль (сторона повреждения) → максимум 1 гекс за ход
- Отслеживание: перевернуть жетон на сторону с MVD после движения

#### 4.4. Оперативные соединения (ТФ)
- Движение со скоростью самого медленного корабля
- Каждый корабль ТФ отслеживает расход топлива отдельно
- Создание/разделение:
  - Корабли в одном гексе, не преследуемые → можно создать ТФ
  - Корабли можно добавлять/удалять из ТФ в том же гексе
  - Минимум 2 корабля в ТФ, иначе убрать маркер ТФ

#### 4.5. Особые случаи движения
- Преследуемый юнит входит в туманный гекс → убрать маркер "Преследуется"
- Первый туманный гекс, в который вошли во время движения, все равно объявляется противнику
- Аварийное топливо:
  - При достижении "Топливо закончилось" → маркер на Трек хода (+10 ходов)
  - Корабль помечается маркером "Аварийное топливо"
  - Ограничение: только 1 гекс за ход (без расхода FP)
  - Если не добрался до порта/заправки → корабль удаляется из игры

#### 4.6. Воздушные юниты
- Игнорируют рельеф
- Макс. движение = Максимальная скорость (гексов)
- Маркеры пути полета:
  - 2 маркера Пути полета Поиска "бесплатно"
  - Дополнительные маркеры Пути полета Поиска стоят: текущий Уровень видимости в MP каждый
  - Маркер Пути полета Атаки можно сбросить только в гексы с преследуемым вражеским морским юнитом
- Ограничения:
  - Нельзя размещать маркеры при видимости X
  - Нельзя размещать маркеры в туманных гексах во время тумана
  - Должен иметь возможность приземлиться в конце движения

### 5. Интеграция систем

#### 5.1. Последовательность фаз
1. Фаза видимости → расчет уровня видимости, проверка тумана
2. Фаза преследования → попытки перевода "Обнаружено" → "Преследуется"
3. Фаза движения:
   - Движение преследуемых (объявление местоположения)
   - Движение остальных юнитов
   - В конце: "Преследуется" → "Обнаружено"
4. Фаза поиска → активный поиск, обнаружение вражеских юнитов
5. Фаза случайных событий → случайное обнаружение, охота на конвои

#### 5.2. Взаимодействие с другими системами
- Видимость влияет на поиск, преследование, бой, воздушные атаки
- Обнаружение необходимо для инициации боя
- Движение влияет на факторы поиска и возможность обнаружения
- Туман и видимость X блокируют большинство действий

### 6. Технические требования

#### 6.1. Данные для хранения
- Уровень видимости (1-X)
- Статус погоды (трек погоды)
- Статус тумана (да/нет)
- Маркеры обнаружения на каждом гексе ("Обнаружено"/"Преследуется")
- Факторы поиска по каждому гексу
- Информация о движении кораблей (MVD)
- Статусы кораблей (ремонт, заправка, патруль)

#### 6.2. API/События
- `visibility_phase` — фаза видимости
- `pursuit_phase` — фаза преследования
- `movement_phase` — фаза движения
- `search_phase` — фаза поиска
- `random_events_phase` — фаза случайных событий
- События обнаружения кораблей
- События изменения маркеров обнаружения

#### 6.3. Проверки и валидация
- Проверка возможности поиска (видимость, туман, факторы поиска)
- Проверка возможности преследования (условия, модификаторы)
- Проверка возможности движения (ограничения, топливо, класс скорости)
- Проверка автоматического снятия маркеров (туман, видимость X)
