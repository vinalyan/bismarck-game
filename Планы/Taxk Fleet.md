### Из правил игры (Правила.md):

1. ТФ всегда должен включать минимум два корабля - иначе маркер TF убирается с карты
2. Максимального количества кораблей в одном ТФ нет
3. Можно добавлять NavalUnit в ТФ, если они находятся в том же гексе, что и маркер ТФ их DetectionLevel не равен DetectionLevelSighted
4. Можно выводить корабли из  ТФ если DetectionLevel не равен DetectionLevelSighted

### Логика именования:

- Союзники: TF-1, TF-2, TF-3...
- Немцы: KG-1, KG-2, KG-3... (Kampfgruppe)
- Номера переиспользуются при роспуске TF

### Характеристики TF:
- Скорость определяется самым медленным кораблем (F > M > S > VS)
- TF наследует поведение юнитов (движение, поиск, обнаружение)
- TF отображается как единый маркер на карте

### 🎯 Ключевые различия в архитектуре:

1. **Task Force - это контейнер:**
   - Не имеет собственных характеристик боя
   - Управляет группой юнитов как единым целым
   - Поведение определяется составом юнитов

2. **NavalUnit - это индивидуальный юнит:**
   - Имеет все характеристики корабля
   - Может быть частью Task Force
   - Управляет собственным состоянием

3. **Наследование поведения:**
   - Task Force наследует базовое поведение юнита (движение, поиск, обнаружение)
   - Но делегирует сложные операции (бой, повреждения) входящим юнитам

Эта архитектура позволяет Task Force вести себя как юнит на карте, но при этом не дублировать сложную логику индивидуальных кораблей!


## Дивижение. 


При клике на TF по аналогии с кликом на NavalUnit вызвываем ручку 
GET /api/games/{gameId}/units/{unitId}/available-moves

При вызове этой ручки вызывам ручку 
GET /api/games/{gameId}/units/{unitId}/available-moves
для всех NavalUnit внутри TF.
Применяется самый худший результат. 

Есть один корабдь дает 2 гекса, а другой 1, то применяется 1. 
Если у какого-то корабля есть no_movement_turns_left>0, то это значение применяется ко всему TF (сам параметр no_movement_turns_left в TF выносить не надо, каждый раз рассчитываем.)
Если у кораблей есть запрещенные для перемещения гексы, то применяется для всего TF. Например ограничения движения немецких DD.

Корабли внутри TF не имеют своего position. И перемещаются вместе с TF.
При выборе NavalUnit из состава TF для этого NavalUnit не надо рассчитвать available-moves

Топливо расчитывается для каждого корабля отдельно
