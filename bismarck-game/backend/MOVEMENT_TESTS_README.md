# 🚀 Тестирование системы движения кораблей

Этот набор тестов предназначен для комплексного тестирования системы движения кораблей в игре "Погоня за Бисмарком".

## 📋 Обзор тестов

### 1. `test_movement.sh` - Основные тесты движения
**Назначение:** Базовое тестирование всех типов кораблей и их движения

**Что тестируется:**
- ✅ F тип (Быстрые корабли) - движение на 1-2 гекса, расход топлива
- ✅ M тип (Средние корабли) - движение на 1 гекс, условный расход топлива
- ✅ S тип (Медленные корабли) - движение на 1 гекс, маркер "Нет движения 2"
- ✅ VS тип (Очень медленные корабли) - движение на 1 гекс, маркер "Нет движения 4"
- ✅ Ограничения топлива
- ✅ Доступные гексы для движения
- ✅ Ошибки движения

### 2. `test_movement_scenarios.sh` - Детальные сценарии движения
**Назначение:** Детальное тестирование специфических сценариев движения

**Что тестируется:**
- 🎯 **F тип:** 4 сценария (0 гексов, 1 гекс, 2 гекса, ошибка 3+ гексов)
- 🎯 **M тип:** 3 сценария (первое движение, повторное движение, ошибка 2+ гексов)
- 🎯 **S тип:** 3 сценария (движение, маркер "Нет движения", ошибка повторного движения)
- 🎯 **VS тип:** 3 сценария (движение, маркер "Нет движения 4", ошибки в следующих ходах)
- 🎯 **Доступные гексы:** для всех типов кораблей
- 🎯 **Ошибки:** 3 типа ошибок (недоступный гекс, неверный формат, тот же гекс)

### 3. `test_movement_integration.sh` - Интеграционные тесты
**Назначение:** Тестирование взаимодействия всех компонентов системы

**Что тестируется:**
- 🔄 **Смешанные типы кораблей:** одновременное движение разных типов
- 🔄 **Переходы между ходами:** обновление состояния после смены хода
- 🔄 **Фаза администрирования:** обновление маркеров "Нет движения"
- 🔄 **Синхронизация фронтенд-бэкенд:** согласованность данных
- 🔄 **Отображение активных гексов:** корректность для всех типов
- 🔄 **Уведомления об ошибках:** различные типы ошибок
- 🔄 **Производительность:** множественные запросы и параллельные движения

### 4. `run_all_movement_tests.sh` - Главный файл
**Назначение:** Управление всеми тестами движения

**Возможности:**
- 🎛️ **Интерактивный режим:** выбор конкретных тестов
- 🎛️ **Автоматический режим:** запуск всех тестов
- 🎛️ **Проверка зависимостей:** curl, jq, bash
- 🎛️ **Статистика результатов:** процент успешных тестов

## 📝 Правила движения (справочник)

### F тип (Быстрые корабли)
- **Максимальное движение:** 2 гекса за ход
- **Расход топлива:**
  - 0 гексов: 0 FP
  - 1 гекс: 0 FP
  - 2 гекса после 0-1 гекса в предыдущий ход: 1 FP
  - 2 гекса после 2 гексов в предыдущий ход: 2 FP

### M тип (Средние корабли)
- **Максимальное движение:** 1 гекс за ход
- **Расход топлива:**
  - Первое движение: 0 FP
  - Повторное движение: 1 FP

### S тип (Медленные корабли)
- **Максимальное движение:** 1 гекс за 2 хода
- **Расход топлива:** 0 FP
- **Ограничения:** маркер "Нет движения 2" после движения

### VS тип (Очень медленные корабли)
- **Максимальное движение:** 1 гекс за 4 хода
- **Расход топлива:** 0 FP
- **Ограничения:** маркер "Нет движения 4" после движения

## 🐛 Отладка

### Общие проблемы
1. **Сервер недоступен**
   ```bash
   # Проверить статус сервера
   curl http://localhost:8080/health
   ```

2. **Пользователи не существуют**
   ```bash
   # Создать тестовых пользователей
   curl -X POST http://localhost:8080/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{"username":"testuser1","password":"password123"}'
   ```

3. **Файлы не исполняемые**
   ```bash
   # Сделать файлы исполняемыми
   chmod +x test_movement*.sh
   chmod +x run_all_movement_tests.sh
   ```
