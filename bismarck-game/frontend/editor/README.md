# Редактор структур карты для Bismarck Game

Веб-утилита для создания и редактирования структур карты (порты, каналы, маршруты конвоев и т.д.)

## Возможности

- Создание портов с настройкой типа и возможностей
- Создание каналов между двумя гексами
- Разметка маршрутов конвоев
- Определение воздушных секторов
- Разметка зоны Ла-Манша
- Установка ограничений для эсминцев
- Экспорт и импорт структур в JSON формате
- Визуализация структур на карте с цветовым кодированием

## Установка и запуск

```bash
cd bismarck-game/frontend/editor
npm install
npm start
```

Приложение запустится на порту 3001.

## Использование

1. Выберите тип структуры в левой панели
2. Кликайте по гексам на карте для добавления в структуру
3. Нажмите "Сохранить" для создания структуры
4. Заполните форму свойств структуры
5. Используйте "Экспорт JSON" для сохранения файла
6. Используйте "Импорт JSON" для загрузки структур

## Формат JSON

Структуры сохраняются в следующем формате:

```json
{
  "ports": [
    {
      "type": "port",
      "hexIds": ["O32", "O33"],
      "portType": "norway",
      "name": "Port Name",
      "canRefuel": true,
      "canReloadTorpedoes": true
    }
  ],
  "canals": [...],
  "convoyRoutes": [...],
  "airSectors": [...],
  "englishChannel": {...},
  "restrictedDD": {...}
}
```

## Цветовая схема

- Порты: синий (#2196f3)
- Каналы: зеленый (#4caf50)
- Маршруты конвоев: оранжевый (#ff9800)
- Воздушные секторы: голубой (#00bcd4)
- Ла-Манш: фиолетовый (#9c27b0)
- Ограничения эсминцев: красный (#f44336)
