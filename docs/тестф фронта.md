## Основные команды для запуска тестов:

### 1. **Запуск всех тестов (интерактивный режим)**
```bash
cd bismarck-game/frontend
npm test
```
Запускает все тесты и следит за изменениями файлов.

### 2. **Запуск всех тестов один раз (без watch)**
```bash
cd bismarck-game/frontend
npm test -- --watchAll=false
```

### 3. **Запуск конкретного теста**
```bash
cd bismarck-game/frontend
npm test -- hexUtils.test.ts --watchAll=false
```

### 4. **Запуск всех тестов утилит**
```bash
cd bismarck-game/frontend
npm test -- src/utils --watchAll=false
```

### 5. **Запуск с покрытием кода (Coverage)**
```bash
cd bismarck-game/frontend
npm test -- --coverage --watchAll=false
```
Создаст отчет в `coverage/lcov-report/index.html`.

### 6. **Для CI/CD (один запуск, покрытие)**
```bash
cd bismarck-game/frontend
CI=true npm test -- --coverage --watchAll=false
```

## Быстрая справка

**Интерактивные команды в watch mode:**
- `a` - запустить все тесты
- `f` - запустить только упавшие тесты
- `q` - выйти
- `p` - фильтр по имени файла
- `t` - фильтр по имени теста

Полная инструкция сохранена в `bismarck-game/frontend/TESTING.md`.

Для проверки созданных тестов выполните:
```bash
cd bismarck-game/frontend
npm test -- src/utils --watchAll=false
```

Это запустит все тесты из директории `utils`, которые были созданы на этапе 1.
